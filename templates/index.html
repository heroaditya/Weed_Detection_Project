About This System

This weed detection system uses a YOLOv10 model trained on agricultural field images to identify weeds among crops. Upload a field image to get:

  • Visual identification of weeds with bounding boxes
  • Confidence level for each detection
  • Location information within the image

The system helps farmers identify problem areas in their fields and target weed control measures more effectively.
